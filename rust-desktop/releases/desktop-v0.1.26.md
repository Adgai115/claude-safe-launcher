# Claude 环境检查器 v0.1.26

本版本继续面向 Windows x64，重点改善真实用户遇到的 VPN 处理说明、自动修复和问题反馈流程。

## 主要变化

- 顶部“查看修复方案”现在会打开可操作的说明，并明确解释 TUN、全局模式和非 Clash VPN 的适用条件。
- 保留唯一主入口“检查并修复”。VPN 尚未就绪时，用户连接 VPN 并返回应用后会自动复查并继续原修复流程。
- 设置中的“允许自动修复可控项目”现在覆盖启动检查、手动检查和 VPN 返回复查。已授权的 Clash TUN、已保存节点、可信基准和 Windows 时区可静默修复。
- Claude 运行期间检测到风险变化时，会弹窗让用户选择保持运行或关闭 Claude。
- 新增“反馈问题”入口和 GitHub 问题模板。诊断文件始终由用户决定是否手动上传。
- 脱敏诊断升级为 schema v2，增加固定结果码、权重、得分、耗时、平台架构和重复事件折叠，同时继续排除 IP、VPN 节点名、用户名、文件路径和原始检查说明。
- 改善更新失败后的重试、Claude 运行锁定、签名失败提示和版本变化后的重新检查。

## 更新方式

v0.1.25 可以发现本版本，并通过应用内更新入口下载完整安装器。安装器会识别原安装位置并沿用应用数据。此发布不包含 Tauri 直接补丁，因此不会绕过 v0.1.25 内置的更新签名校验。

Windows 安装包当前没有 Authenticode 代码签名，系统可能显示安全提醒。Release 同时提供 `SHA256SUMS.txt`，GitHub Actions 会为发布资产生成构建来源证明。

## 验证范围

- Windows 桌面格式、Rust 核心及桌面测试通过。
- Windows x64 完整安装器构建和结构检查通过。
- 隔离环境中的签名直接升级、下载中断重试、带空格自定义路径、配置保留和托盘监控恢复通过。
- 修复说明、反馈入口、VPN 返回自动续检和授权后的静默修复通过 Playwright 交互验证。

非 Clash VPN 的连接、断开、同节点重连三态实机验收尚未完成。应用可以识别并核对常见 Windows VPN 接口，但不能代替第三方 VPN 客户端完成连接、TUN 或节点切换。
