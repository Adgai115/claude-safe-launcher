# Claude 环境检查器 v0.1.27

本版本继续面向 Windows x64，重点增加 Clash Mi 的自动连接、TUN 安全配置和候选节点验证，并改善第三方 VPN 接口识别。

## 主要变化

- “检查并修复”现在可以识别 Clash Mi，在 Claude 未运行且已允许自动修复时，尝试启动或重连 Clash Mi、启用全局模式与 TUN、关闭代理内核 IPv6 并清理旧连接。
- Clash Mi 当前节点未达标时，会依次验证有限数量的候选节点。只有 API、DNS、官方支持地区和 IP 风险均通过的节点才会成为新基准；没有合格候选时恢复原节点并继续阻止启动。
- 修复完成后重新探测真实出口、接口、地区和时区，只有完整检查无阻断时才保存可信基准。
- 检测到自定义 Claude Code API 地址时，可将当前用户配置恢复为官方 `https://api.anthropic.com`。
- Claude 运行期间仍保持只读。监控发现风险变化时由用户确认是否关闭 Claude；确认关闭后自动进入同一个“检查并修复”流程。
- 改善非 Clash VPN 的 Windows 虚拟接口识别，并为接口不一致、未知虚拟接口和 Fake IP 等情况提供更明确的脱敏原因码。
- 修复 Clash Mi 图形界面仍在运行但服务已断开时无法自动重连的问题。

## 更新方式

v0.1.26 可发现本版本。兼容性验证通过后，应用内更新使用签名的直接更新包，沿用原安装路径、配置和监控状态；Release 同时提供完整安装器。

Windows 安装包当前没有 Authenticode 代码签名，系统可能显示安全提醒。应用内直接更新包仍使用 v0.1.25 起内置的更新公钥校验。

## 验证范围

- Windows 桌面格式、Rust 核心及桌面测试通过。
- Windows x64 完整安装器构建和结构检查通过。
- 发布候选提交需通过从 v0.1.26 到 v0.1.27 的隔离签名直接升级测试。
- Clash Mi 自动修复包含单元与流程测试，但真实用户环境中的连接、断开和同节点重连三态实机验收尚未完成。

应用不会绕过 Windows UAC，也不会在 Claude 运行时静默修改系统或强制结束 Claude。需要提升权限时仍需用户确认。
