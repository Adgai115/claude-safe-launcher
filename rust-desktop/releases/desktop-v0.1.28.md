# Claude 环境检查器 v0.1.28

本版本继续面向 Windows x64，重点修复 Clash Mi 已开启全局和 TUN 后仍无法自动确认、修复并建立可信环境基准的问题。

## 主要变化

- 修正 Clash Mi 未显式填写控制器地址时的默认端口：使用官方默认的 `127.0.0.1:9090`，不再误用 Clash Verge 的 `9097`。
- “检查并修复”在 Clash Mi 内核已经运行时，也会同步全局模式、TUN、TUN 覆盖和关闭代理内核 IPv6 的持久配置，再通过本地控制器复查实时状态。
- Clash DNS 使用公网解析模式时，只要 Clash 控制器与 Windows TUN 均已确认，系统 DNS 直接显示“通过”，不再停留在“参考”。
- 为代理内核、TUN 适配器、控制器、策略组和节点状态补充明确的脱敏原因码，后续用户导出的诊断日志可以区分具体断点。
- 自动修复链恢复后，可继续核对节点与出口，并自动建立缺失的出口、地区和时区基准；Claude 运行期间仍只读，不修改环境。

## 更新方式

v0.1.27 可发现本版本，并通过应用内更新入口下载经 GitHub SHA-256 校验的完整安装器。安装器会沿用原安装路径、配置和监控状态。

本次公开发布继续使用无 AWS 的 GitHub Actions 流程，只提供完整安装器和 `SHA256SUMS.txt`。本机现有 PEM 文件不是与 `updater.pub` 配对的 Tauri 更新私钥，因此不发布 `latest.json`、直接更新包或伪造签名。Windows 安装包当前没有 Authenticode 代码签名，系统可能显示安全提醒。

## 验证范围

- Windows 桌面格式、Rust 核心及桌面测试通过。
- Windows x64 完整安装器构建和结构检查通过。
- 新增 Clash Mi 与 Clash Verge 独立默认控制器端口测试。
- 新增 Clash 公网 DNS 在控制器与 Windows TUN 均确认后转为通过的测试。
- 真实用户反馈日志已确认 v0.1.27 连续多次自动修复均卡在控制器识别；本版本修复该确定性根因。

应用不会绕过 Windows UAC，也不会在 Claude 运行时静默修改系统或强制结束 Claude。需要提升权限时仍需用户确认。
