# Windows v3.5.3 发布说明

默认 Windows 安装入口切换到 `windows/claude-panel.ps1`，将实际检查、修复复查、实时卡片和评分统一。根目录 v4 JSON 预览、规则目录、旧测试和 macOS 实现保留，避免升级覆盖已有接口。

- 15 组检查，官方地区缓存带来源和时效。
- Windows TCP 连接归属补足代理元数据缺失，匹配当前进程、源地址和端口及目标端口。
- 客户端告警扫描区分限制、权限、认证、账单和限流，只返回分类；无日志使用中性状态。
- 统一带权重的结构化进度和结果，按组计数；实时发现偏差、修复复查和扣分联动，防止旧快照覆盖新结果。
- 将耗时观测移到独立只读进程；观测和检查有超时上限，面板继续响应，超时不终止 Claude。
- 变量备份升级为 Windows DPAPI CurrentUser 加密，并限制访问权限。
- 保留既有代理/TUN 路径，正常 Claude Code 变量不因存在而自动清除；不注入或修改 Claude，不断开其连接或强制重启。
- 文档明确区分「面板观测」和「通过启动 Claude 开启的独立监控」，关闭面板不会停止已经启动的独立监控，Claude 退出后监控结束。

## 验证范围

Windows PowerShell 5.1 下运行新版的脚本回归、地区/连接/日志分类回归，以及 Edge 下的桌面和移动视口回归。发布时还保留并执行根目录原有规则、变量修复及问题说明测试。模拟检查使用独立临时目录和合成探测，不对真实账号发请求。

macOS 代码和根目录 v4 预览接口未做此次功能迁移；不能将 Windows 新增验证结果等同于这些实现已覆盖相同行为。
